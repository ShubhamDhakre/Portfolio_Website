# Shubham Dhakre — Portfolio Website

> A personal portfolio inspired by the universe, modern interface design, and my curiosity about technology.

Welcome to my portfolio repository! 👋

I'm **Shubham Dhakre**, a Computer Science Engineering student and web developer who enjoys exploring how things work, learning new technologies, and turning creative ideas into interactive experiences.

I built this portfolio to showcase my skills, projects, and journey as a developer. Instead of following a conventional portfolio design, I wanted to create something that reflects my personality and interests — especially my curiosity about **space, physics, and the way our universe works**.

## 🌌 The Inspiration

Space has always fascinated me. From the mysteries of black holes and distant galaxies to the fundamental laws of physics, I find the universe a constant source of curiosity and inspiration.

I wanted to bring a little of that feeling into my portfolio. The visual direction takes inspiration from the depth, atmosphere, and minimalism associated with space, creating a digital experience that feels modern, immersive, and personal.

My goal was not just to build a website that displays information, but to make exploring it feel interesting in itself.

## ✨ Design Philosophy

### Glassmorphism and Modern UI

The interface uses glass-inspired visual elements, subtle transparency, layered surfaces, and soft lighting to create a clean, futuristic appearance.

My design inspiration comes from the polished glass-like interfaces and smooth visual details found in **Google's design language, Apple's iOS, and Vivo's operating-system UI**. I took inspiration from these styles while developing my own approach to the portfolio.

I wanted the interface to feel lightweight and elegant without sacrificing readability or usability.

### Interactive 3D Experience

I use **Three.js** to explore 3D visuals and bring more depth to the experience. Combined with CSS animations and interactive UI elements, these details help make the portfolio feel more dynamic than a traditional static website.

I also focus on keeping animations purposeful, so they enhance the experience rather than distract from the content.

### Light and Dark Themes

I enjoy interfaces that adapt to different visual preferences. That's why the portfolio includes light and dark themes, with the goal of maintaining a consistent design and comfortable viewing experience in both modes.

## 💻 Run Locally

If you'd like to explore the project on your own machine:

**1. Clone the repository**

```bash
git clone https://github.com/ShubhamDhakre/Portfolio_Website.git
```

**2. Enter the project directory**

```bash
cd Portfolio_Website
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

**5. Create a production build**

```bash
npm run build
```
